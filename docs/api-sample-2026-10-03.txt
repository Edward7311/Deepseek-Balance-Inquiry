【六个接口分别是什么】

  by_api_key/amount   每日 tokens，按 (API key × 模型) 交叉 —— 柱状图数据源
  by_api_key/cost     每日金额，同样交叉 —— 柱状图的另一个数据源
  usage/amount        本月 tokens，按模型汇总
  usage/cost          本月金额，按模型汇总
  users/get_user_summary   账户余额拆分 + 累计消费
  users/get_api_keys  API key 列表

⚠️ 注意：这是真实账户的数据快照，含 token 用量和余额。
